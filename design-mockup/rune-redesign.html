Introduction

Rune is a self-hostable operating system for a research day: tasks, projects, a LaTeX notebook, and an optional team mode, run from your own server.

Why self-hosted

Your tasks, notebooks, and run history stay on infrastructure you control. Nothing about Rune requires a hosted account to be useful — npm run setup gets a working instance running locally in a few minutes.

Quick start

Clone the repository, run npm install, then npm run setup. The setup tool asks where Rune will run and writes the configuration for it.

Core ideas

A project groups related tasks and can hold one or more notebooks — each a single continuous LaTeX document, not a folder of pages. A run tracks a compute job or lab instrument session and can be referenced directly from the notebook that writes it up.
